## О проекте

**ElectroKit** помогает инженеру или домовладельцу быстро оценить:

- расчётные токи и номиналы автоматических выключателей;
- сечение кабеля с учётом **падения напряжения (ΔU)** и **тока короткого замыкания** в конце линии (характеристика **C**);
- материал жил (**медь / алюминий**) и отдельные ряды сечений;
- подбор и проверки **УЗО** (10 / 30 / 100 / 300 мА, влажные зоны, линия ввода);
- **спецификацию и ориентировочную смету** материалов;
- предупреждения по лимитам мощности (7 кВт / 15 кВт) и мягкие подсказки по безопасности.

Интерфейс **на русском**, адаптирован под **десктоп и мобильные устройства** (карточки линий, выезжающее меню помещений, увеличенные зоны нажатия).

> ⚠️ **Важно.** Результаты носят **ознакомительный характер** и не заменяют проектную документацию, обследование и согласование с энергоснабжающей организацией. Цены в смете — **условные**, ориентир розницы.

## Возможности

| Область | Что делает приложение |
|--------|------------------------|
| **Линии нагрузки** | Мощность, напряжение, длина трассы, розеточная группа, влажная зона, ввод, материал жил |
| **Расчёты** | *I = P / (U·cos φ)* для 230 В; для 400 В — симметричная нагрузка *I = P / (√3·U·cos φ)*; автомат с учётом ×1,13 |
| **Кабель** | Совместное ограничение ΔU ≤ 5% и *I<sub>кз</sub> ≥ 10·I<sub>ном</sub>* (кривая C); отдельные ряды для Cu и Al |
| **УЗО** | Автоподбор по названию (ванна, санузел, стиралка…), зоне и линии ввода >7 кВт; мин. номинал УЗО — **ступень выше** автомата |
| **BOM / смета** | Агрегация автоматов (C + полюса), УЗО, кабеля с **+10% запаса** по длине; умножение на условный прайс |
| **UI** | Таблица на широких экранах, **карточки** &lt;768px; липкая шапка; схема щита (условная DIN-графика) |

## Быстрый старт

Требуется **Node.js** 18+ (рекомендуется LTS).

```bash
# клонировать репозиторий и перейти в каталог
cd ElectroKit

# установить зависимости
npm install

# режим разработки (http://localhost:5173)
npm run dev

# production-сборка → каталог dist/
npm run build

# предпросмотр сборки
npm run preview
```

## Структура репозитория (кратко)

```
ElectroKit/
├── src/
│   ├── App.tsx                 # корневой layout, drawer, липкая шапка

│   └── components/             # таблица / карточки, форма, BOM, схема, баннеры
├── index.html
├── package.json
├── vite.config.ts
├── tailwind.config.js
└── tsconfig.json
```

## Деплой

Соберите проект (`npm run build`) и разместите содержимое каталога **`dist/`** на любом статическом хостинге (Nginx, GitHub Pages, Cloudflare Pages, Vercel и т.д.). Для SPA с клиентским роутингом (если появится) может понадобиться правило fallback на `index.html` — в текущей версии один экран, достаточно отдачи статики.
